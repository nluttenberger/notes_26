Python packages are class and function libraries, 
i.e. groupings of classes and functions for defined areas of application. 

A package contains an __init__.py file, which can be empty, 
and any number of Python modules that group related functions and classes. 

In Python, a module is any Python source file, e.g. main.py or decisiontree.py.

After a Python package has been created, 
the classes and functions defined in it can be imported into other Python scripts 

You can import either the entire package or just individual modules or classes/functions.

Python has a built-in library - the Python Standard Library, which is available immediately after installation, 
and includes many basic functions such as mathematical functions, system functions, file access, encryption etc.

A current list of Python libraries and software is maintained in the Python Package Index (PyPI). ^oEZcy5S3
