> [!summary] Course goals
> This course provides participants with the skills to identify and apply suitable conceptual approaches for analyzing large-scale tabular datasets and extensive text corpora, with a strong emphasis on tailoring these methods to their own research questions. Within this framework, particular attention is given to data science methods.
> Participants learn how to transform tabular and textual data into network and graph structures, enabling the use of corresponding analytical and visualization tools. The course also introduces Jupyter notebooks and the Python programming language, including key packages such as Pandas for two-dimensional data, SciKit-Learn for natural language processing, and NetworkX for network construction and analysis.
> In addition, participants are introduced to AI-based support for programming, which facilitates their continued engagement with the methods and tools presented in the course.

> [!summary] Prior knowledge
> A basic understanding on what a programming language is. The concept of graphs. Minor experience with AI prompting. 

>[!summary] Course duration
> 8 × 90 min

> [!summary] Course scope
> The course begins with a comprehensive introduction to the Python programming language and the fundamental concepts of the Pandas package. Teaching and hands-on exercises take place in Jupyter notebooks, which we use as an interactive environment for software development and testing.
> To investigate the capabilities of Python and Pandas in a practical setting, we work with several datasets. One of these contains information on approximately 8,800 films and television shows and is publicly available on [Kaggle](https://www.kaggle.com/) (see below for further details on Kaggle). Particular emphasis is placed on the systematic identification and mitigation of data quality issues in this dataset.
> Next, we learn how to transform the dataset into a graph—specifically, a bimodal graph—that highlights several important structural features. We then project this graph into two single-mode graphs: a co-actor graph and a shared-actor graph.
> Subsequently, we turn to a corpus of texts comprising the inauguration speeches of U.S. presidents. Using methods from natural language processing (NLP), we extract keywords from these speeches and construct graphs based on the extracted terms. Through suitable node coloring, we can visualize how the presidents’ keyword choices have evolved over time.
> In addition, participants are introduced to AI-based support for programming, which facilitates their continued engagement with the methods and tools presented in the course.
> According to Wikipedia, _“Kaggle is a data science competition platform and online community for data scientists and machine learning practitioners under Google LLC. Kaggle enables users to find and publish datasets, explore and build models in a web-based data science environment, collaborate with other data scientists and machine learning engineers, and participate in competitions addressing data science challenges.”_
