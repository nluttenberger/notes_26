> [!summary] Course title
> Huge tables and large corpora of text: Creating insight by applying network and AI methods 

> [!summary] Short title
> Texts and Tables 

> [!summary] Course goals
> The primary objective of this course is to enable participants to identify and apply appropriate methodological approaches for the analysis of large-scale tabular datasets and extensive text corpora, with particular emphasis on adapting these methods to their individual research questions. The course places a strong focus on network analysis and artificial intelligence (AI) techniques.
> The analytical framework is illustrated through the exploration of several exemplary datasets, among them the Netflix Streaming dataset comprising information on approximately 8,800 films and television shows, which is publicly available on [Kaggle](https://www.kaggle.com/) (for further details on Kaggle, see below). Special consideration is given to the identification and mitigation of data quality issues within this dataset.
> For data exploration and analysis, participants will employ a range of software tools, including Python as a general-purpose programming language, the Pandas library for two-dimensional data processing, Natural Language Processing (NLP) techniques for textual data, NetworkX for the construction and analysis of network structures, and AI-based methods for higher-level computational tasks.
> According to Wikipedia, _“Kaggle is a data science competition platform and online community for data scientists and machine learning practitioners under Google LLC. Kaggle enables users to find and publish datasets, explore and build models in a web-based data science environment, collaborate with other data scientists and machine learning engineers, and participate in competitions addressing data science challenges.”_

> [!summary] Prior knowledge
> A basic understanding on what a programming language is. The concept of graphs. Minor experience with AI prompting. 

>[!summary] Course duration
> 8 × 90 min

> [!summary] Course scope
> The course focus is on a thorough introduction to the Python programming language together with a presentation of the fundamentals of the Pandas and NetworkX software packages. We explain the fundamentals of Natural Language Processing, and show experimental AI prompting with the LM Studio package. We use the Netflix Streaming Data dataset provided by Kaggle as running example; this dataset describes approx. 8800 movies and TV shows. We work together using Jupyter notebooks for software development and testing. The Graphviz application serves as tool for graph visualization with application-specific graph styling methods.
